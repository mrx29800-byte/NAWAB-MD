# NAWAB-MD Plugins

This folder is an active plugin directory. `handler.js` automatically loads every `.js` file that exports `{ commands, run }`.

Included live plugins:
- `status.js` — `.health`, `.ram`, `.nodeinfo`
- `utilities.js` — `.whoami`, `.plugininfo`

Use `.plugins` to see loaded plugin commands. Restart the bot after adding or changing a plugin.
